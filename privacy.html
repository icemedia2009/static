PixelArchive Privacy Policy

Effective September 28, 2026 · Version 1.6.1 and later

PixelArchive runs locally. It does not send page content, screenshots or personal information to a server. The current free release has no account, payment or license-verification feature.

1. Information we collect

None. We do not collect names, email addresses, account data, browsing history, visited URLs, search history, device identifiers, IP addresses, location data, analytics or advertising data.

2. Where captures are stored

Captures and PDFs are saved to your downloads folder according to your settings. Up to 60 recent captures are stored locally in browser IndexedDB for the result page and can be cleared there. An image is written to the system clipboard only when you choose “Copy to clipboard”. Screenshot data does not leave your device.

3. Permissions

debugger temporarily raises rendering density for a capture you initiate and disconnects after it finishes. tabs names files and checks whether a page can be captured. downloads, storage, offscreen, scripting, clipboardWrite, contextMenus and <all_urls> are used only to create, save, locally process and provide the screenshot functions you choose. The extension does not upload page content or make a browsing index.

4. Remote code

All executable code is packaged with the extension. PixelArchive does not load remote code, use a CDN, eval, new Function or external services.

5. Contact

For privacy questions: pixelarchive-web@outlook.com
